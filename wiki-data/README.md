# Отслеживаемые данные вики

`vanilla-ru-26.2.json` содержит только русские названия предметов, блоков,
эффектов, зачарований и атрибутов из официального языкового ассета Minecraft
26.2. Снимок нужен как точный fallback: локализация Matcha переопределяет лишь
собственные названия.

Обновление и проверка выполняются через Mojang version manifest:

```powershell
bun run vanilla:sync
bun run vanilla:sync --check
```

Скрипт фиксирует asset index и SHA-1 исходного файла, поэтому незаметно
переключиться на другую версию Minecraft он не может.
