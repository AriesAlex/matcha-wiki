# Отслеживаемые данные вики

`project.json` — единственный источник текущих версий пака, Minecraft и ревизии
форка, а также проверяемых официальных URL и хешей.

`vanilla-ru.json` содержит только русские названия предметов, блоков, эффектов,
зачарований и атрибутов из официального языкового ассета целевой версии
Minecraft. Снимок нужен как точный fallback: локализация Matcha
переопределяет лишь собственные названия.

Обновление и проверка выполняются через Mojang version manifest:

```powershell
bun run vanilla:sync
bun run vanilla:sync --check
```

Скрипт фиксирует asset index и SHA-1 исходного файла, поэтому незаметно
переключиться на другую версию Minecraft он не может.
