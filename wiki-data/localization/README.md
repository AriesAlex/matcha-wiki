# Контракт локализации pack

`runtime-text.json` — канонический реестр текстов, которые можно безопасно
перевести через Minecraft `translate` components. Он хранит английский оригинал,
русский перевод и точный runtime-target. Генератор синхронизирует эти ключи в
`en_us`, `en_au`, `en_ca`, `en_gb` и `ru_ru`.

Сейчас реестр покрывает:

- 134 заголовка и описания достижений;
- 3 описания jukebox songs;
- 8 сообщений из исполняемых `mcfunction`;
- 7 уже использовавшихся автором ключей, которые отсутствовали в английской
  таблице;
- 11 штатных `filled_map.*`, которые есть во встроенном `en_us` целевой версии
  Minecraft
  и поэтому корректно используют английский fallback, даже когда их нет в
  отдельном `ru_ru` asset.

## Почему не переведены все literals

`deferred-literals.json` — генерируемый машинный инвентарь строк, которые
намеренно оставлены как есть. Имена и lore в результатах рецептов, loot tables и
торговых офферах становятся частью сериализованного `ItemStack`. Замена
`{"text":"..."}` на `{"translate":"..."}` меняет значение компонента: старый и
новый предмет могут перестать складываться, совпадать в predicates или
обрабатываться функциями pack.

Поэтому массово конвертировать строки из `recipe`, `loot_table` и
`villager_trade` нельзя. Перед переносом любой записи из deferred-инвентаря
нужна отдельная проверка её runtime- и matching-семантики.

## Работа с реестром

Проверка ничего не переписывает:

```powershell
bun run localization --check
```

После намеренного изменения `runtime-text.json` применить реестр и обновить
deferred-инвентарь:

```powershell
bun run localization --write
```

Чтобы добавить новый переводимый текст:

1. убедиться, что это UI-текст, а не сериализованный компонент предмета;
2. добавить в `entries` точный target, стабильный ключ, `en` и `ru`;
3. для уже существующего `translate` без изменения data-файла использовать
   `languageOnly`;
4. запустить `--write`, просмотреть pack diff и затем запустить `--check`.

Чтобы поддержать ещё одну локаль, нужно добавить её JSON в
`pack/assets/minecraft/lang`, включить код локали в `allLocales` генератора и
явно определить, какой вариант (`en` или новый столбец реестра) она использует.
Не следует молча копировать русский перевод в другую локаль.

Обычные `bun run data`, `bun run test` и `bun run validate` выполняют
read-only аудит. Он падает, если появилась новая literal-строка на безопасной
UI-поверхности, отсутствует перевод используемого ключа или
`deferred-literals.json` больше не соответствует pack.
