# Matcha Wiki

Русская энциклопедия и исправленная редакция
[Matcha Flavoured](https://modrinth.com/datapack/matcha-flavoured).

Оригинальный пак создан Klei. Русский форк, ручная локализация, проверенные
исправления и сопровождение этой редакции выполнены ArieX.

[Открыть вики](https://ariesalex.github.io/matcha-wiki/) ·
[Скачать последний ZIP](https://github.com/AriesAlex/matcha-wiki/releases/latest)

Вики строится по реальным данным пака, а не по вручную переписанному списку:
генератор извлекает предметы, рецепты, достижения, модели, текстуры, loot
tables, торговлю и item components. Рецепты показываются в привычной сетке
Minecraft, а для пользовательских предметов указываются ванильный carrier,
модель и точный файл-источник.

## Что здесь есть

- подробные русские гайды от первого костра до возобновляемого эндгейма;
- разбор еды, смерти, зачарований, экипировки, торговли, мира и рыбалки;
- полный поисковый каталог предметов и рецептов с игровыми текстурами;
- объяснение авторской идеи по оригинальному видео Klei;
- распакованный комбинированный data/resource pack в `pack/`;
- проверенные исправления загрузки, многопользовательской логики, еды, экипировки,
  оберегов, Zephyr и конфликтующих рецептов;
- автоматическая сборка статической Nuxt-вики и воспроизводимого ZIP.

## Установка пака

Релиз состоит из одного комбинированного data/resource-pack ZIP. Не нужно искать два
разных архива: один и тот же файл подключается на клиенте и в мире.

1. Скачайте готовый `.zip` из последнего релиза, а не автоматически добавленный
   GitHub архив исходников.
2. Положите тот же ZIP в `resourcepacks` клиента и включите его.
3. Добавьте ZIP в `datapacks` нужного мира.
4. Для существующего мира выполните `/reload` и проверьте достижения Matcha.

Namespace, recipe ID и модельные ID сохранены, поэтому исправленная редакция
предназначена для прямой замены соответствующей редакции Matcha. Перед заменой
активно используемого пака всё равно стоит закрыть мир штатным способом.

## Разработка

Нужен [Bun](https://bun.sh/).

```powershell
bun ci
bun run dev
```

Основные команды:

```powershell
bun run data       # заново извлечь каталог и публичные ассеты из pack/
bun run localization --check # проверить языковые ключи и deferred-реестр
bun run validate   # lint, typecheck, tests, static site и релизный ZIP
bun run pack       # собрать версионированный ZIP в dist/
```

`pack/` является источником истины игровых данных. `generated/`, `public/generated/` и
`dist/` не редактируются вручную: они пересобираются скриптами.
Текущие версии пака, Minecraft и ревизии форка объявляются только в
`wiki-data/project.json`; имя артефакта, шапка сайта и сборка получают их оттуда.

Контракт безопасной локализации и порядок добавления нового языка описаны в
[`wiki-data/localization/README.md`](wiki-data/localization/README.md).

Каждое исправление описано в `wiki-data/fixes/*.json`; страница
[«Исправления и известные проблемы»](https://ariesalex.github.io/matcha-wiki/known-issues)
строит из этих manifest публичный проверяемый реестр.
